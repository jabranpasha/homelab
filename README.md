# Homelab: SSH Brute-Force Attack & Detection

To get some experience in the field and learn through doing, I decided to set up a homelab and eventually work my way up to creating an attack & detection scenario with multiple VMs and a SIEM tool.

To get started I needed a hypervisor, and I went with VMWare WorkStation Pro because it's free and I've heard it's easy to work with.

For my first ever virtual machine I decided to go with Ubuntu Server, because I've heard that Ubuntu is the most beginner-friendly, and I wanted to learn by using the CLI and not having to rely on a graphical interface that I would have with the desktop version.
